# Default neuron branch context

The main 3D panel now loads actual segmentation branches on first entry to a task. The image plane remains a spatial reference within this branch view. It no longer requires a manual segment pick or a hidden Neuroglancer session before displaying anatomy context.

Four prepared mesh assets are hosted with the application. Each was generated by sampling the documented recipient soma coordinate in the public `seg_m1300` source and capturing the genuine multiresolution mesh subchunks drawn by the bundled Neuroglancer renderer. No skeleton was converted into a membrane and no geometry was invented or interpolated. These are navigation meshes with partial, view-selected level-of-detail coverage, not exhaustive membrane reconstructions.

`data/starter-meshes/manifest.json` records each exact soma pick, the source URL, physical transform, fragment keys, source manifest bounds, vertex/triangle counts, and binary SHA-256. The loader verifies source identity, soma binding, hash, binary layout, finite coordinates, and valid indices before displaying geometry. All coordinates are global nanometers; the renderer rebases them locally without a half-voxel offset.

The candidate picked at a recipient soma is used for navigation across that recipient's tasks. This is **not** a verified mapping from release661 to v1300 and is **not** an anatomical decision. Candidate status and unconfirmed identity are retained in the saved selection and UI. The original catalog and source mappings remain unchanged.

Saved segment selections and 3D camera positions take priority. First-time initialization is recorded in the task view, so deleting the default candidate does not cause it to reappear on reload. Asynchronous loads are checked against the active task epoch and current selected IDs before attaching geometry. Reusing the same recipient mesh requires no additional fetch during the session.

The full Neuroglancer view starts only when requested or when an additional uncached selected structure needs its source mesh. The prepared branch context is retained when the native view changes level of detail; it is not replaced by just the currently visible fragments.

Rebuild: start the local server, then run `node tools/build-starter-meshes.mjs`. This performs live public-source sampling and writes only derived assets in this website. `tools/browser-starter-meshes.mjs` checks first-open branches with all external HTTPS requests blocked, plus recipient switching, saved camera restoration, and explicit removal persistence, without clicking a load-3D button or taking screenshots.
